description=[h1]Install[/h1]
description=[img]https://da.gd/bmeKA[/img]
description=1. Subscribe and wait until Steam has downloaded the item.
description=2. Mods (main menu): enable [b]PZ_Optimization[/b]. A window shows the install command with this item's folder in it.
description=3. Press [b]Copy the command[/b], open PowerShell (Windows: Start menu, type powershell) or a terminal (Linux, macOS), paste, Enter.
description=4. Quit the game (QUIT): the installer waits for that, then copies the files. Start the game: Options now has an [b]Optimizations[/b] tab. Disable the mod again, it only carries that window.
description=
description=[b]Without the window[/b], one line (finds this item's download itself, waits for the game to close):
description=Windows (PowerShell): [code]irm https://github.com/xD3I/PZ_Optimization/releases/latest/download/install.ps1 | iex[/code]
description=Linux, macOS (terminal): [code]curl -fsSL https://github.com/xD3I/PZ_Optimization/releases/latest/download/install.sh | bash[/code]
description=Or run install.ps1 / install.bash from this item's folder (steamapps/workshop/content/108600/3805285544/mods/PZ_Optimization/42/). The installer checks the game version, never overwrites a file and never modifies projectzomboid.jar; the first boot is a few seconds slower (caches under Zomboid/pzopt/).

description=[h1]Stock game again, or uninstall[/h1]
description=[b]To compare with stock:[/b] Options > Optimizations > "Disable all (stock game)", restart. Nothing is removed; "Enable all" brings it back.
description=[b]To uninstall:[/b] Options > Optimizations > [b]Uninstall PZ Optimization[/b] (main menu). The game closes, then every installed file is removed and the launcher settings it changed are put back. Your settings in Zomboid/pzopt/ stay.
description=[b]Uninstall before you unsubscribe:[/b] unsubscribing deletes this item, not the installed files. Already unsubscribed, or no game? The one-line installer with -Uninstall: [code]& ([scriptblock]::Create((irm https://github.com/xD3I/PZ_Optimization/releases/latest/download/install.ps1))) -Uninstall[/code] (Linux, macOS: the curl line ending in [b]| bash -s -- --uninstall[/b]).

description=[h1]What it does[/h1]
description=Project Zomboid loads and bakes the map in chunks; on stock, the loading, baking and lighting work of a busy screen lands in the same frame and shows as stutter while driving or turning. These overrides move that work off the game thread, spread it over frames, and cache what stock recomputes every frame (puddles, rain, cutaways, lights, sound zones). At 5120x2160 on an RTX 4090: driving p99 frame time 19 -> 8 ms, uncapped ~270 -> ~500 fps, thunderstorms 83 -> 188 fps.

description=[h1]How it works[/h1]
description=The launcher (ProjectZomboid64.json) searches the game folder before projectzomboid.jar, so a loose .class file with the same name as one in the jar replaces it. The item holds those files (707 files: 101 shadowed game classes, the pzopt package, Lua, preview clips, a manifest) under [b]pzopt-classes[/b]; projectzomboid.jar is never modified. A guard checks the game revision and the sha256 of every shadowed stock class at start-up; on any difference the game runs as stock (one log line).
